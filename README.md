# Pizza Ordering Program

A simple Dart pizza ordering program that demonstrates the use of a switch-case statement and a while loop.

## Pizza Prices

- Small: 5 USD
- Medium: 7 USD
- Large: 10 USD

## Features

- Allows the user to select a pizza size.
- Allows the user to enter the quantity.
- Calculates the total payment.
- Uses a switch-case statement to determine the pizza price.
- Uses a while loop to allow continuous ordering.
